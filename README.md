### Slönguspil (JavaFX + Maven)

Þetta er einfalt slönguspil forritað í Java með JavaFX og Maven.

---

## Keyrsla

1. **Clone-aðu projectið**
   git clone https://github.com/gauti94/Vidmotsf-Lokav.git
2. **Opnaðu verkefnið með IntelliJ**
   Þarft að vera með bæði Maven og JavaFX sett upp
4. **Compile-aðu með maven**
   Auðveldast að gera það í maven icon-ið hægra megin í IntelliJ
   Verkefni 3 -> Plugins -> Compiler -> Compiler:compile
   
   ![image](https://github.com/user-attachments/assets/c892ce34-a639-4dfc-b393-b87902050f36)

6. **Keyrðu forritið með javafx plugin-inu**
   Sömuleiðis er hérna auðveldast að nota maven stikuna
   Verkefni 3 -> Plugins -> javafx -> javafx:run
   
   ![image](https://github.com/user-attachments/assets/51916e96-1f39-435a-b2af-d61e705104be)
